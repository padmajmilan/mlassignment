### Key Observations

**1. Logistic Regression**
- Strong accuracy (89.50%) but conservative predictions
- Excellent AUC-accuracy ratio (0.5560)
- Biased towards majority class prediction
- Suitable as baseline model

**2. Decision Tree**
- Lowest accuracy (82.50%) among all models
- Lowest discriminative power (AUC: 0.4819)
- Shows signs of overfitting/underfitting
- Needs pruning and hyperparameter tuning

**3. K-Nearest Neighbors**
- Tied for highest accuracy (89.50%)
- Best discrimination ability (Highest Precision: 0.5000, Non-zero F1: 0.0870)
- Best MCC score (0.1295) showing moderate correlation
- Best practical model for this imbalanced dataset

**4. Naive Bayes**
- Good accuracy (89.50%)
- Highest AUC score (0.5770) - best probabilistic ranking
- Conservative hard predictions but strong probability estimates
- Useful for confidence scores despite poor hard predictions

**5. Random Forest**
- Good accuracy (89.50%)
- Moderate AUC (0.4977)
- Still biased by class imbalance
- Requires class weighting or SMOTE for improvement

**6. XGBoost**
- Good accuracy (87.00%)
- Moderate AUC (0.4874)
- Negative MCC suggests worse than random performance
- Needs hyperparameter optimization and class balancing
